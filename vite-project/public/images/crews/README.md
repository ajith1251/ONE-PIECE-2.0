# public/images/crews

## Purpose
Home for all crew/faction artwork in One Piece 2.0 (emblems, group art, faction banners).

## Contents
- **Crew/faction artwork only** — one file per crew, named by entity ID.
- Future examples: `straw-hat-pirates.*`, `red-hair-pirates.*`, `marines.*`

## Rules
- Filename base = crew `id`. Any supported format.
- Emblems/crest SVGs are acceptable here (SVG is appropriate for emblems).
- Do NOT place character portraits or ship art here.
