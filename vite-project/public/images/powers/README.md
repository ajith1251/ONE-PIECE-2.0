# public/images/powers

## Purpose
Home for all power-system artwork in One Piece 2.0 — Devil Fruits, Haki, combat styles, weapons.

## Contents
- **Power artwork only** — one file per power, named by entity ID.
- Future examples: `gomu-gomu-no-mi.*`, `mera-mera-no-mi.*`

## Rules
- Filename base = power `id`. Any supported format.
- The corresponding data folder is `src/data/fruits/` (schema: `power-schema.md`); asset names follow the power entity ID convention.
- Do NOT place character portraits here (even devil-fruit users).
