# public/images/shared

## Purpose
Home for assets that are NOT owned by a single entity — fallback images, generic artwork, logos, icons.

## Contents
- **Fallback / placeholder art** (e.g., `placeholder.*`) — used when an entity has no artwork.
- **Generic artwork** — art that serves the whole project (backgrounds, generic crew visuals).
- **Logos & icons** (SVG appropriate here).

## Rules
- Anything here is shared by design — never duplicate it into an entity folder.
- If an asset belongs to one entity, it does NOT belong here; it goes in that entity's folder.
- Future placeholder components will reference these fallbacks; nothing is implemented yet.
