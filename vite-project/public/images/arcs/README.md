# public/images/arcs

## Purpose
Home for all arc/saga artwork in One Piece 2.0 (key-art, saga banners).

## Contents
- **Arc artwork only** — one file per arc, named by entity ID.
- Future examples: `marineford-arc.*`, `wano-arc.*`, `alabasta-arc.*`

## Rules
- Filename base = arc `id`. Any supported format.
- Arc IDs always carry the `-arc` suffix to stay globally unique (see `src/data/shared/entity-ids.md`).
- Do NOT place location art here (e.g., `marineford.*` belongs in `locations/`).
