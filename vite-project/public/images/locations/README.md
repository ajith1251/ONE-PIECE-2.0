# public/images/locations

## Purpose
Home for all location artwork in One Piece 2.0 (seas, islands, kingdoms, marine bases, sky islands, underwater).

## Contents
- **Location artwork only** — one file per location, named by entity ID.
- Future examples: `marineford.*`, `alabasta.*`, `wano.*`, `egghead.*`

## Rules
- Filename base = location `id`. Any supported format.
- No display names, no version suffixes, no required extension.
- Do NOT place character/arc art here.

## Status
📂 FOUNDATION (Phase 3A) — empty by design. Existing legacy portraits (`public/images/img1.png`–`img10.png`) are untouched; migration is a future phase.
