# public/images/characters

## Purpose
Home for all character artwork in One Piece 2.0.

## Contents
- **Character artwork only** — one file per character, named by entity ID.
- Future examples: `monkey-d-luffy.*`, `roronoa-zoro.*`, `nami.*`

## Rules
- Filename base = character `id` (see `src/data/shared/entity-ids.md`). Any supported format (PNG/JPG/JPEG/WEBP/AVIF/GIF).
- No display names, no version suffixes, no required extension.
- Do NOT place crew/arc/location art here.

## Status
📂 FOUNDATION (Phase 3A) — empty by design. Existing legacy portraits (`public/images/img1.png`–`img10.png`) are untouched; migration is a future phase.
