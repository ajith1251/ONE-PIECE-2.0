# public/images/battles

## Purpose
Home for all battle artwork in One Piece 2.0 (showdown key-art, war scenes).

## Contents
- **Battle artwork only** — one file per battle, named by entity ID.
- Future examples: `marineford-war.*`, `luffy-vs-kaido.*`

## Rules
- Filename base = battle `id`. Any supported format.
- Do NOT place location or character art here even if they appear in the battle.
